## 用户原话
> 再做一张海报吧，带上二维码的海报。你不要像之前那个海报一样写什么几款游戏在里面，你就写这个所有小V助手，然后就直接开始用。因为后面我们会更新的嘛，你不要把话写死了。然后把几个桌游盒放上面做装饰

## 要求
1. **文案不能写死**：不要出现“四款桌游”这类数量，也不要列出具体游戏名，因为以后还会加游戏。
   - 主标题：桌游小助手
   - 副标题和号召语用通用说法，比如“线下开局 · 计分 · 规则问答”“扫码打开，直接开始用”“持续更新更多桌游”。可以自己斟酌，保持简短。
2. **游戏盒做装饰**：
   - 把 `public/games.json` 里带 `url` 的游戏（现在是 7 款）的官方盒封面 `public/img/box-<key>.jpg` 摆上去，做成立体盒子，可以参考旧海报的 3D 盒写法。
   - 按 `box` 字段的真实比例缩放。
   - 排法自己设计，要好看、不杂乱，例如错落成弧形或叠成一堆。盒子是装饰，不能挡住标题和二维码。
   - 读取 `games.json` 来决定放哪些盒子，不要把游戏名写死在 HTML 里。以后加了游戏，重新导出就会自动多一个盒子。盒子太多放不下时，要有合理的处理，比如只放前 N 个，或者自动缩小。
   - 只用官方原图，**不要用 AI 生成或重绘任何游戏盒封面**。
3. **背景**：沿用 `海报/源文件/bg.png`，这是之前生成的原创灯下桌游桌。
4. **二维码**：
   - 链接 `https://boardgame.leisurecat.cloud`，用 Python `qrcode` 生成，纠错级别 H。中间放骰子小图标，沿用旧海报的做法。
   - 导出后用 Chrome 的 `BarcodeDetector`（Playwright 打开图片后调用）验证能解出这个网址。高清版和缩到 700 像素宽的版本都要能解出来。
5. **输出**（旧海报文件保留，不要覆盖）：
   - `海报/源文件/poster_v2.html`：新的排版源文件。
   - `海报/桌游小助手海报v2_高清.jpg`：2480×3720。
   - `海报/桌游小助手海报v2_手机.jpg`：宽 1240，适合发微信。
   - 一张 700 像素宽的预览图：`/tmp/claude-501/codex_tasks/shots/poster_v2_preview.jpg`。
