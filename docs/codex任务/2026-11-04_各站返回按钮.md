# 2026-11-04 · 各助手站加“返回”按钮（统一规矩）

本说明会分别发给每个站各自的 Codex 任务。每个任务开头会写明：站名、项目目录、本地端口、测试目录。

## 用户原话
> 我发现很多页面左上角没有回到主页的按钮，应该开局后能返回助手首页，助手首页能返回总首页

## 统一规矩（所有站一致）
系列总首页：https://boardgame.leisurecat.cloud （“桌游小助手”）。

1. **助手首页**（`index.html` 未进房间时的落地页）：左上角加 **“‹ 全部游戏”**，链接到 `https://boardgame.leisurecat.cloud`。
2. **进入房间 / 开局后的所有界面**：开局设置、对局、计分、结算都算，包括惨剧轮回的剧作家视图和公开视图。左上角加 **“‹ 首页”**，点了回到本助手首页。
   - 只是离开当前界面，**不能结束或清空房间**。之后从首页的房间列表，或者再输入房间码，还能回来。
   - 如果项目里已经有“离开房间”的动作（例如 `app.js` 里的 `case 'leave'`），复用它，并确认它不会删除房间数据。
3. **其他独立页面**（`guide.html`、`history.html`，以及本站特有的页面，如 `cards.html`、`scripts.html`、`roles.html`）：左上角加 **“‹ 返回”**，链接到本助手首页 `/`。
4. **样式**：小胶囊按钮，跟随本站已有的视觉体系，用 CSS 变量，不另起风格。
   - 位置要考虑刘海屏安全区（`env(safe-area-inset-top)`、`env(safe-area-inset-left)`）。
   - 在图片头图上也要看得清，必要时用半透明深色底。
   - 不能遮挡现有的标题、房间码、连接状态、右下角“规则”按钮等元素。真有冲突时，可以把原有元素做最小挪动。
   - 手机 390 宽下不能横向溢出，点击区域至少 36px 高。
5. **不能出现在结算长图里**：如果按钮落在 html2canvas 截图区域内（如 `#shot`），加 `data-html2canvas-ignore`。
6. 这次只加返回入口，**不改其他功能**，不重构。
