# 2026-11-04 · 定先后手的手指轮盘：大小圈没对齐

工作目录：`桌游助手首页/`。相关文件：`public/order.js`（`finger()`，每根手指生成一个 `.fring`）、`public/tools.css`（`.fring` 相关样式）、`tests/test_tools.mjs`（手指轮盘用例通过 CDP 模拟 3 根手指）。

## 问题
用户原话：“你那个决先后手的圈没对齐啊，大小圈”。

每根手指下面是一个 `.fring`（120×120，`border: 6px`），里面叠了几层圆：
- `.fring::before`：外圈的脉冲光环，`inset: -18px`；
- `.fring svg`：按住时逐渐填满的进度圆，目前写的是 `inset: -12px; width: 144px; height: 144px`，再加上 `transform: rotate(-90deg)`；
- `.fring .num`：结果出来后浮在上方的数字徽章（这个本来就在圈外，不用和圈同心）。

我初步看到的原因：绝对定位的子元素是相对于 `.fring` 的**内边距盒**定位的，6px 的边框不算在内。svg 同时设了 `inset` 和固定宽高，两组约束冲突，结果 svg 往右下偏了大约 6px，所以进度圆和主圈、外圈不同心。请自己核实这个判断，并检查其他圈层有没有同样的问题。

## 要求
1. 主圈（`.fring` 的边框）、外圈脉冲光环（`::before`）、进度圆（svg 里的 circle），这三者的圆心要**完全重合**，并且都正好落在手指位置上（`.fring` 的 `left/top` 就是手指坐标）。下面三种状态都要成立：
   - 按住时：进度圆从 0 填到满；
   - 轮转高亮时：`.hl` 带 `scale` 动画；
   - 出结果后：`.first`、`.lose` 状态。
2. 进度圆的半径看起来要比主圈稍大一圈，跟现在的视觉保持一致，只是同心对齐。起点仍在 12 点方向，顺时针填充。
3. 只改 `tools.css` 里 `.fring` 相关的样式。必要时可以微调 `order.js` 里生成 svg 的那一行。不要改其他功能。
