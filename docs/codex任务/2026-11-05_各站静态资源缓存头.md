`桌游助手首页/`、`匹兹堡助手_多人房间/`、`伯明翰助手/`、`奥丁的盛宴助手/`、`惨剧轮回助手/`、`血染钟楼助手/`、`阿纳克遗迹助手/`、`阿瓦隆助手/`。
每个项目都是 Cloudflare Workers 加静态资源，静态资源目录是 `public/`，具体见各项目的 `wrangler.jsonc` 里的 `assets.directory`。

## 背景
大陆访客走跨境线路，一次往返要两三百毫秒。现在所有静态资源的响应头都是 `cache-control: public, max-age=0, must-revalidate`，每张图每次访问都要回源确认一次，浪费往返时间。

字体已经单独处理（Cloudflare Fonts，`/cf-fonts/` 由 Cloudflare 给出一年缓存），**这次不要动字体**。

## 要做的
用 Workers Static Assets 支持的 `_headers` 文件（放在各项目的静态资源目录根部，即 `public/_headers`）为静态资源设置缓存，规则如下：
1. **图片**（`.jpg .jpeg .png .webp .gif .svg .ico` 等，不管放在哪个子目录）：`Cache-Control: public, max-age=604800`，即 7 天。按各项目实际的图片目录写规则，比如 `/img/*`、`/guide/*`、教程配图目录等。
   - 先在每个项目里用 `find public -type f` 看清楚图片实际放在哪些目录，再写规则。
   - 如果图片和 HTML/JS 混放在同一个目录里，就按文件扩展名写规则。
   - 写之前先查 `_headers` 是否支持你要用的通配写法，以 Cloudflare 官方文档为准，不支持的写法不要用。
2. **固定版本的第三方库**（如 `public/vendor/` 下的 html2canvas）：`Cache-Control: public, max-age=31536000, immutable`。
3. **HTML、项目自己的 JS / CSS / JSON（含 `games.json`）保持现状**，不要给它们加长缓存，否则更新后用户会看到旧版本。
4. 视频之类由 Worker 代码返回的资源（如 `/media/*`）不受 `_headers` 影响，**不要改 Worker 代码**。
5. 以后如果需要替换同名图片，用户最多要等 7 天才能看到新图。把这一点写进各项目 README 的部署说明，加一句话即可。
